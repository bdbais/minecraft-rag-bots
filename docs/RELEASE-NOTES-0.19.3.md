# Minecraft RAG Bots v0.19.3 — Beta

Release prerelease per beta tester.

## Novità

- coordinamento cooperativo tra bot e giocatori verso l’obiettivo Ender Dragon;
- progressione guidata: sopravvivenza, strumenti, Nether, stronghold e End;
- recupero automatico dei bot bloccati: raccolta legna, esplorazione e costruzione riparo;
- azione `build_shelter` per posizionare blocchi nel mondo;
- ruoli di squadra basati su personalità: raccoglitore, costruttore, esploratore, difensore e speedrunner;
- profilo hardware-DNA per confrontare il contributo computazionale dei computer;
- manuale d’uso italiano e screenshot dell’interfaccia;
- controllo aggiornamenti GitHub con proposta manuale.

## Requisiti beta

- Minecraft Java Edition e server di test autorizzato;
- Ollama locale con modello agente ed embedding, oppure provider cloud configurato;
- Windows x64: usare l’installer allegato;
- Linux/macOS: usare il pacchetto sorgente e seguire il manuale, oppure gli artifact generati dal workflow GitHub Actions.

## Avvertenze

È una versione beta: il bot può fallire, perdere tempo o richiedere istruzioni manuali. Fare backup di memoria e biografie. Non usare credenziali reali in server non fidati.
