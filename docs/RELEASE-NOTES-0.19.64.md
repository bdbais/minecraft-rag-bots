# Minecraft RAG Bots 0.19.64

- Aggiunta la caccia controllata agli animali commestibili quando il bot è affamato e non ha cibo.
- Il bot evita di cacciare se ha già una coppia di animali adatta all'allevamento.
- La caccia è separata dal combattimento contro i mob ostili e viene registrata nelle statistiche di vita.
