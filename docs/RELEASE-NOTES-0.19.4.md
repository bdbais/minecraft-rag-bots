# Minecraft RAG Bots v0.19.4 — Beta

Release beta che include la correzione dei comandi brevi e dei saluti.

## Correzioni

- il bot risponde ai saluti dei giocatori;
- “raccogli legna”, “prendi i tronchi” e comandi equivalenti attivano la raccolta deterministica;
- “impugna”, “equipaggia”, “tieni” e “usa” selezionano un oggetto realmente presente nell’inventario;
- test automatici: 56/56 superati.

## Installazione

Usare l’installer Windows oppure il pacchetto sorgente della release. È una versione beta: usare server autorizzati e conservare un backup delle memorie.
